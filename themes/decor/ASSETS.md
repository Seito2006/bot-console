# Downloaded Mei Theme Decorations

These small SVG ornaments are bundled locally so the extension does not request them at runtime. They are recolored in the interface with CSS masks and gradients.

- `sakura.svg` — “Sakura.svg” by Mnmazur, released under CC0 1.0. Source: https://commons.wikimedia.org/wiki/File:Sakura.svg
- `corner-ornament.svg` — “Corner Ornament Black Up Right.svg”, author listed as unknown / antique ornament, released under CC0 1.0. Source: https://commons.wikimedia.org/wiki/File:Corner_Ornament_Black_Up_Right.svg
- `floral-corner.svg` — Paul Bürck's 1899 “Floral border 03 corner” design; the SVG adaptation is CC0 1.0 and the underlying work is public domain. Source: https://commons.wikimedia.org/wiki/File:Floral_border_03_corner_by_Paul_B%C3%BCrck.svg

The decorative SVG files were downloaded from Wikimedia Commons. This note is kept with the files for provenance; CC0 does not require attribution.
