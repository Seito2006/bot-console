# ไฟล์อัปเดตบอท

วางการ์ด PNG หรือ JSON ที่ส่งออกจาก SillyTavern ในโฟลเดอร์นี้ แล้วระบุชื่อบอทและชื่อไฟล์ใน [bot-update.json](../bot-update.json) ดูตัวอย่างการตั้งค่าใน [คู่มือ Bot Console](../README.md#แนบไฟล์อัปเดตบอท)

กำหนด `lorebook` เป็นชื่อไฟล์ Lorebook แบบ JSON เพื่ออัปเดตและเชื่อมเข้ากับการ์ดพร้อมกัน กำหนด `cover` เป็นชื่อรูปได้เมื่อใช้การ์ด JSON กำหนด `version` ใน bot-update.json และเพิ่มเลขนี้เมื่อปล่อยชุดไฟล์ใหม่
